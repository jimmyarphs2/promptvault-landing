# PromptVault Landing Page

High-converting dark landing page for AI video prompt packs.

## Deploy to Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import this repository
3. Deploy

## Video

Upload `hero-video.mp4` to the root of this repository (or replace the video source in `index.html`) for the hero video to play.

## Local preview

Open `index.html` in a browser.
